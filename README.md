# 🌊 Water Cycle Educational Game

An interactive **educational game** for children aged 8-12 to learn about the **water cycle**, water conservation, and environmental protection. Built with **Unity 2022** and **C#**, featuring engaging gameplay, puzzles, and an AI-powered NPC guide.

---

## 🎮 Features

- Interactive Water Cycle Simulation (steam, clouds, precipitation)
- Puzzle-based challenges
- AI NPC helper for guidance
- Co-op and single-player modes
- Procedural level generation
- Educational quizzes

## 🛠 Installation

1. Clone the repository:
```bash
git clone https://github.com/alirezahkim/WaterCycleGame.git
```

2.  Open in Unity 2022.2.21f1.

3.  Open Assets/Scenes/MainScene.unity.

4.  Play and explore!
